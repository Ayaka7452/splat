# Gaussian Splat Viewer（魔改版）

基于 [antimatter15/splat](https://github.com/antimatter15/splat)（MIT License）修改的
WebGL 3D 高斯泼溅查看器。无需构建步骤、无外部依赖，直接打开 `index.html` 即可使用。

## 新增功能

### 1. SPZ 格式全版本支持（v1–v4）

- 支持 Niantic SPZ 格式全部版本：v1 / v2 / v3（gzip 压缩）与 v4（ZSTD 多流压缩）
- 内置纯 JS ZSTD 解码器（[fzstd](https://github.com/101arrowz/fzstd)，MIT License），
  gzip 使用浏览器原生解压接口，支持 zlib / raw-deflate 自动回退
- 文件选择与拖拽均可加载 `.spz`，加载失败时给出具体错误原因
- 修复了部分浏览器下 gzip 解压报错信息被吞掉（"The operation was aborted"）的问题

### 2. 左右 / 上下翻转按钮

- 右上角并排两个按钮：**Flip Horizontally**（快捷键 `H`）与 **Flip Vertically**（快捷键 `F`）
- 两个开关相互独立、可叠加，通过投影镜像实现，不影响模型数据与深度排序

### 3. 以模型为中心的环绕旋转

- 加载后自动以点云中位数作为模型中心（对离群点稳健），相机始终环绕模型中心旋转并正对模型
- 鼠标拖拽、滚轮、单指滑动、`I`/`J`/`K`/`L` 键环绕均以模型中心为轴心

### 4. 移动端手势方向修正

- 双指平移 / 旋转、单指环绕与翻转开关状态联动：开启翻转后手势方向依然符合直觉
  （上滑画面上移、顺时针双指画面顺时针）

### 5. 控制面板折叠 + 关闭文件

- 右上角 `−` 小按钮可折叠 / 展开全部控制按钮（默认展开）
- **Close File** 可卸载当前模型、复位视角，便于重新加载

## 问题修复与精简

- 修复加载 `cameras.json` 后仍使用旧相机内参的问题
- 移除蓝色立方体加载动画，加载状态改为文字提示 + 进度条
- 清理调试日志、冗余计算与死代码

## 操作方式

页面左上角 "Controls" 内有完整操作说明，常用操作：

- 鼠标 / 单指：拖拽环绕，滚轮 / 双指捏合缩放
- `WASD` / 方向键：视角与移动，`Q`/`E` 翻滚，`Space` 跳跃
- `0-9`：切换预置相机视角，`-`/`+` 循环切换
- `P`：恢复默认动画，`V`：把当前视角存入网址
- 拖拽 `.ply` 文件自动转换为 `.splat` 并下载
